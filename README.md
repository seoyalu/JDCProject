# JDC CAMPUS 겨울방학 프로토타입

수정 명세서 v2와 해녀몽이 겨울 디자인을 반영한 대학생 제주 리워드 서비스입니다. 실제 프로젝트 경로는 `C:\workflow\git\JDCProject`입니다.

## 실행

Node.js 24.22.1 이상, pnpm 11.25.0을 사용합니다.

```sh
pnpm install
pnpm dev
pnpm check
```

`pnpm check`는 Prettier 형식 확인, Vitest 테스트, TypeScript 검사와 Vite 배포 빌드를 실행합니다. GitHub의 푸시·PR CI에서도 같은 검증을 수행합니다. 개발 기본 주소는 http://localhost:5173 입니다.

## 겨울방학 체험 시나리오

1. 홈의 `인증하고 500P 받기` → 재학/휴학 선택 및 데모 동의 → CAMPUS PASS 발급, **500P**.
2. `나의 겨울 제주 버킷리스트` 참여 시작 → 경험 1개 이상 저장 → **100P**.
3. 지도에서 잠긴 현장 미션을 확인합니다.
4. `제주공항 도착 인증하기` → QR 또는 GPS 체험 → 데모 인증 완료 → **500P**, 현장 미션 해금.
5. `성산일출봉 방문하기` → 데모 인증 완료 → **150P + 스탬프 1개 + 100XP**.
6. 지도에서 성산일출봉의 해녀몽이 완료 마커, 방문일과 보상을 확인합니다.
7. 보유 **1,250P**로 JDC 10% 할인쿠폰 **500P** 교환 → **750P**, 쿠폰함 발급 확인.
8. MY에서 포인트 원장, 완료 미션, 관심 미션과 해녀몽이 성장을 확인합니다.

미션은 여행 전 4개, 현장 8개, 여행 후 1개입니다. 장소 탐험률은 현장 8곳만을 분모로 사용하고, PASS의 스탬프 수는 전체 완료 미션 수입니다. 지도는 실제 이동 경로가 아닌 인터랙티브 일러스트입니다.

## 시즌과 데모 날짜

- 캠페인: **2026.12.20 ~ 2027.02.28**, 한국 시간 기준. 종료 경계는 2027.03.01 00:00입니다.
- 기본 체험 시각: **2027.01.05 12:00 KST**. 시즌 전 발표에서도 전체 흐름을 재현할 수 있고 화면 상단에 항상 체험 날짜를 표시합니다.
- MY → 알림 및 체험 설정에서 겨울방학 체험 모드를 끄면 실제 날짜 기준으로 예정·잠금·진행·종료 상태를 확인합니다.
- 날짜 모드를 바꿔도 기록은 남습니다. 시뮬레이션으로 발급한 인증·쿠폰의 발급일보다 이전인 실제 날짜에서는 사용할 수 없습니다. 전체 시연은 겨울방학 모드에서 진행하세요.
- 인증 전 0P로 시작하고 인증 보상은 1회 500P입니다. 초기화는 인증·포인트·쿠폰·완료 기록·성장·설정을 모두 초기 상태로 되돌립니다.
- 해녀몽이는 300XP마다 성장하며 최대 LV.5입니다. 포인트 소비는 스탬프·경험치에 영향을 주지 않습니다.

## 구조

```text
src/
  app/                     앱 경로·통합 테스트
    state/                 인증·미션·보상 원장·상태 검증·저장
  domains/
    home/                  겨울 시즌 홈
    map/                   장소 핀·필터·방문 기록·탐험률
    missions/              시즌 데이터·상태·미션 상세·인증·완료
    benefits/              대학생 쿠폰 교환·발급·사용
    pass/                  대학생 인증과 CAMPUS PASS
    profile/               MY·성장·활동·초대·설정
  shared/
    ui/                    공통 UI·모달·해녀몽이·성장 카드
    lib/                   숫자·날짜 표시
  styles/                  CSS Modules·반응형 디자인
public/images/             겨울 배너·해녀몽이·지도
```

React, TypeScript, Vite, React Router, Context + useReducer, localStorage, CSS Modules와 Lucide를 사용합니다. 기존 도메인별 구조를 유지합니다.

## 저장 및 검증

새 저장 키는 `jdc-campus-demo-v2`입니다. 인증·보상 정책이 달라졌으므로 v1 기록을 임의로 변환하지 않으며 이전 저장 키는 그대로 보존합니다. 복원 시 완료 미션을 재검증하고 포인트·쿠폰 원장, XP, 날짜와 중복을 대조합니다. 브라우저 저장이 차단되면 안내 후 현재 세션 내에서 동작합니다.

UI와 리듀서에서 인증, 시즌 기간, 선행 미션, 참여 시작, 유효한 입력, 인증 방식, 잔액, 중복 보상과 쿠폰 유효기간을 확인합니다. 이는 실제 서비스의 서버 보안 검증을 대체하지 않습니다.

## 체험 범위

- 대학생 인증은 김제디 가상 계정의 데모이며 실제 학생증·학번을 수집하지 않습니다.
- QR/GPS는 명시적인 데모 버튼으로 장소 도착을 시뮬레이션합니다. 카메라나 위치 API를 요청하지 않습니다.
- 버킷리스트·친구 계획·위시리스트·취향 선택은 브라우저에 기록됩니다. 위시리스트 상품은 예시입니다.
- 친구 초대 링크는 클립보드 복사 기능이며 외부 메시지를 전송하지 않습니다. 실제 초대자 추적이나 피초대자 검증은 없고 `초대 성공 체험`으로 1회 300P를 지급합니다.
- 알림 설정은 이 브라우저의 표시 설정이며 푸시 발송과 연결되지 않습니다.
- 쿠폰 가격·조건은 프로토타입 예시이며 실제 JDC 주문에 사용할 수 없습니다.
- 관리자 콘솔과 외부 대학 인증·주문·위치 시스템 연동은 이번 발표용 범위에 포함되지 않습니다.

## 배포와 디자인 에셋

Vercel 배포 설정은 기존 `vercel.json`을 사용합니다. 빌드 `pnpm build`, 출력 `dist`, SPA 새로고침 경로가 설정되어 있습니다. 외부 게시와 공개 접속 QR 생성은 배포 주소가 결정된 뒤 진행합니다.

겨울 배너, 투명 배경 해녀몽이, 제주 지도는 내장 image_gen으로 제작해 WebP로 저장했습니다. 정확한 파일 경로와 프롬프트는 `문서/겨울방학_디자인_에셋.md`에 기록했습니다. 폰트는 Noto Sans KR이며 네트워크가 차단되면 시스템 한글 폰트로 표시됩니다.
