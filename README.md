# JDC CAMPUS

대학생을 위한 제주 활동 리워드 서비스의 발표용 모바일 웹 프로토타입입니다.

## 실행

Node.js 22.12 이상과 pnpm을 사용합니다.

```sh
pnpm install
pnpm dev
```

개발 주소: http://localhost:5173

```sh
pnpm test
pnpm build
pnpm preview
```

## 기술과 구조

- React + TypeScript + Vite
- React Router: 화면별 URL과 브라우저 뒤로 가기
- CSS Modules + CSS 변수: 데스크톱과 모바일 반응형 디자인
- Context + useReducer: 포인트, 미션, 쿠폰 상태를 함께 갱신
- localStorage: 브라우저별 체험 기록 저장 (키: `jdc-campus-demo-v1`)
- Lucide: UI 아이콘
- Vitest: 보상 정책과 저장 데이터 검증

```text
src/
  App.tsx                    화면과 경로
  main.tsx                   앱 진입점
  components/UI.tsx          PASS, 미션 카드, 접근성 모달 등 공통 UI
  data/catalog.ts            미션과 쿠폰 데이터
  state/campus.ts            상태 모델, 리듀서, 저장 데이터 검증
  state/CampusContext.tsx    공통 상태와 브라우저 저장
  state/campus.test.ts       보상 흐름 테스트
  styles/global.css         공통 스타일과 디자인 변수
  styles/App.module.css     화면별 반응형 스타일
public/images/               제주 배너 이미지
vercel.json                 Vite 배포 및 SPA 경로 설정
```

## 발표 시나리오

1. 홈에서 체험 계정 `제주대학교 김제디`와 웰컴 포인트 **300P** 확인
2. `JDC 면세점 방문` 미션 → `방문 인증 시작하기` → `데모 인증하기`
3. **200P**와 `설레는 제주` 스탬프 획득, 잔액 **500P** 확인
4. 혜택 화면에서 `무료배송 쿠폰`을 **500P**로 교환
5. 내 쿠폰함에서 발급 확인 및 쿠폰 사용 체험
6. 마이 캠퍼스에서 포인트 적립·차감 내역 확인
7. 다음 시연 전 마이 캠퍼스의 `체험 초기화`로 300P부터 다시 시작

미션은 체험 기간 동안 각 1회만 완료할 수 있습니다. 투표 미션은 선택지를 고른 후 완료합니다. 쿠폰 유효기간은 발급 후 30일이고 스탬프는 쿠폰 교환 후에도 유지됩니다.

## 체험 범위

로그인, 대학생 인증, 실제 현장 QR/GPS, 주문 시스템은 연결되지 않습니다. PASS는 고정된 가상 계정이며 포인트와 쿠폰은 체험용입니다. 인증 화면은 명확히 표시된 데모 버튼으로 작동합니다. QR 그래픽은 스캔 UI의 설명용 아이콘입니다.

기록은 현재 브라우저에 저장되며 기기 간 공유되지 않습니다. 저장 공간이 막히면 안내를 표시하고 현재 세션 안에서 계속 체험할 수 있습니다. 실제 서비스에서는 서버의 회원 인증, 보상 원장, 중복 방지와 거래 검증이 필요합니다.

## 배포

Vercel에서 프로젝트를 가져와 Vite 프레임워크를 선택합니다. 빌드 명령은 `pnpm build`, 출력 폴더는 `dist`입니다. `vercel.json`에 상세 페이지 새로고침을 위한 SPA 경로 설정이 포함되어 있습니다.

배포 완료 후 공개 HTTPS 주소를 발표용 접속 QR로 만들면 됩니다. 현재 프로젝트는 외부에 자동 게시되지 않습니다. 로컬 개발 주소는 다른 사람의 휴대폰에서 그대로 접속할 수 없습니다.

## 디자인 에셋

참고 이미지의 하늘색, JDC 블루, 귤색 포인트, 둥근 카드와 제주 캐릭터 분위기를 반영했습니다. `public/images/jeju-campus.webp`는 실제 화면에 사용되는 최적화 이미지이며 PNG 원본도 함께 보관했습니다. 이미지 생성 도구와 사용 프롬프트는 `문서/디자인_에셋.md`에 기록되어 있습니다.

폰트는 Google Fonts의 Noto Sans KR을 요청하고, 연결할 수 없으면 시스템 한글 폰트로 표시합니다. 배너 이미지는 프로젝트에 포함되어 있습니다.
